## 1. Desktop App Icons (`desktop/src-tauri/icons/`)

Configured in `desktop/src-tauri/tauri.conf.json` (lines 42–48) and embedded in `desktop/src-tauri/src/tray.rs`.

| `desktop/src-tauri/icons/64x64.png` | PNG | 64 × 64 | 7,453 B | **System Tray Icon**: Embedded directly into native binary via `tauri::include_image!("icons/64x64.png")` in `desktop/src-tauri/src/tray.rs`. **Strict Rust test requirements:** corners at (0,0), (63,0), (0,63), (63,63) must have alpha=0 (transparent); center pixels (24..40, 24..40) must have alpha >= 128 and >16 distinct colors. |
| `desktop/src-tauri/icons/32x32.png` | PNG | 32 × 32 | 2,536 B | **Window Icon (Low-DPI)**: Standard taskbar/window title bar icon for desktop platforms. |
| `desktop/src-tauri/icons/128x128.png` | PNG | 128 × 128 | 21,400 B | **Window/Dock Icon**: Linux launcher and macOS medium-resolution icon. |
| `desktop/src-tauri/icons/128x128@2x.png` | PNG | 256 × 256 | 64,232 B | **Hi-DPI App Icon**: Retina/Hi-DPI displays for macOS/Linux desktop packages. |
| `desktop/src-tauri/icons/icon.ico` | ICO | Multi-res | 81,898 B | **Windows Executable Icon**: Embedded Windows icon containing 16x16, 24x24, 32x32, 48x48, 64x64, and 256x256 frames. |
| `desktop/src-tauri/icons/icon.icns` | ICNS | Apple Iconset | 1,437,080 B | **macOS Bundle Icon**: App icon for `.dmg` and `.app` bundles on macOS. |
